關於這張地圖

這是讀者自行整理的非官方索引，與曼報（Manny Li）無隸屬關係。地圖只記錄「哪篇文章、哪一集談到哪家公司」，加上依公開資料撰寫的公司簡介；文章與節目內容的著作權屬於原作者，請到曼報 Pro 訂閱閱讀。

  • 連結以曼報 Pro 為主：Pro 文章與 Pro Podcast 優先列出，免費電子報與公開 Podcast 作為補充。
  • 公司簡介：依官網、維基百科、財報等公開資料撰寫，不轉述曼報的分析。
  • 閱讀進度：勾選「已讀」只存在你這台裝置的瀏覽器裡，不會上傳。

發現錯漏？歡迎到 GitHub 開 issue 或送 PR，每家公司是一個 YAML 檔，格式說明見 CONTRIBUTING.md。
